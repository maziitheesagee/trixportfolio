TRIX PORTFOLIO - HOW TO PUT IT ONLINE

Every file in this folder sits side by side. There are NO sub-folders.
Upload ALL 15 files (everything except this README is needed) to the SAME place, at the top level of your site:

index.html, work.html, beat-lab.html, services.html, about.html, contact.html
style.css, app.js
pic.jpg, p1.jpg, p2.jpg, p3.jpg
v1.mp4, v2.mp4, v3.mp4

GitHub + Vercel
1. Unzip this file.
2. In your GitHub repository click Add file > Upload files.
3. Open the unzipped folder, select ALL files (Ctrl+A), and drag them in together.
4. Click Commit changes.
5. In Vercel import the repository. Framework Preset: Other. Leave build command and output directory empty. Deploy.

Fastest alternative: app.netlify.com/drop, drag the unzipped folder in.
